How I run multiple teams of Grok Bots

One project equals one channel, one roster, and one Notion board.

The pattern

Instead of a separate chat per bot, organize each project into a channel with a roster. A projects manager bot handles coordination: creating channels, staffing the right bots, and keeping the project database in Notion.

What’s different

  • Reuse existing bots before creating new ones.
  • Cap each channel at six bots besides the PM.
  • Only create a specialist when nothing on the bench fits.
  • Tasks move across a board, with a blocked column that pings the human.

Why it matters

This mimics human team coordination without forcing you to babysit each agent. The board, the manager, and the handoff rules make many-agent setups tractable.
