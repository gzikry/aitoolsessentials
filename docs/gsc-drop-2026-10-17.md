# Search Console drop, checked 2026-10-17

Google impressions fell from about 250–480 a day in late August and early September to about 0 from 2026-09-16. Indexed pages later fell from 640 to 405, with the drops dated 2026-09-21 and 2026-10-04. Not-indexed pages rose to 656: 208 Not found (404), 107 Alternate page with proper canonical, 3 403, 2 noindex, 248 Crawled - currently not indexed, 88 Discovered - currently not indexed.

This note uses git history from 2026-08-21 through 2026-09-15 and live `curl` checks on 2026-10-17. Nothing here was merged or deployed.

## Root cause

Two different reports are moving, and they do not have the same cause.

**The indexed-page drops are from URLs we removed or canonicalized without an HTTP redirect.** From 2026-08-21 through 2026-09-15 the repo published 789 public HTML paths. On current `main`, 59 of those files are gone and the live URL returns 404. Another 23 still exist as noindex refresh stubs (HTTP 200, canonical pointing at the keeper). Three more URLs were listed in the sitemap with no file (`/tools/hootsuite/`, `/tools/hubspot/`, `/tools/mem/`) and also 404. The 2026-09-21 commits turned the duplicate guides into those stubs and removed them from the sitemap the same day Google's indexed count first dropped. There is no commit on 2026-10-04. That second drop matches Google finishing the recrawl of the August and September removals.

**Nothing in the repo turned the whole site off on 2026-09-16.** The daily commit that day (`58d00f69`) left `robots.txt`, `CNAME`, and the homepage canonical untouched. The sitemap stayed at 724 URLs, all on `https://aitoolsessentials.com`. `index.html` did not change. Live checks on 2026-10-17 still show the apex returning 200, `http://` and `www` 301ing to `https://aitoolsessentials.com/`, and `robots.txt` allowing `/`. The impression cliff is the performance report moving before the coverage report. The URLs that had been eligible to rank were the ones that then 404'd or became canonical alternates. The pages Google kept (and the 248 it crawled and chose not to index) are not earning those queries. Redirects repair the 404s and the alternates. They do not make Google index a page it has already crawled and declined.

The 107 "Alternate page with proper canonical" rows are expected. They are not a sitewide canonical bug. See below.

## 403s

The Porkbun proxy (`server: openresty`, `x-service: pixie-sh`) returns this body for a blocked path: `403 Forbidden` / `openresty`. Reproduced on 2026-10-17:

| URL | HTTP | In the repo? |
| --- | --- | --- |
| `https://aitoolsessentials.com/checkout/` | 403 | No file. `robots.txt` already disallows `/checkout/`. `/checkout` 301s to this URL. `/checkout/complete/` is HTTP 200. |
| `https://aitoolsessentials.com/go/` | 403 | No index. `/go/nous/` is HTTP 200. |
| `https://aitoolsessentials.com/xmlrpc.php` | 403 | No file. WordPress probe. |
| `https://aitoolsessentials.com/wp-login.php` | 403 | No file. WordPress probe. |

Search Console's bucket of 3 is this proxy rule, not three missing articles. `/admin/` is HTTP 200 and disallowed in robots. The old `/tools/riverside/` and `/categories/Podcast/` paths are HTTP 404 now that the files are gone. `admin/DOMAIN-SETUP.md` says the proxy returned 403 for those paths while the files existed, which is why `98fcac0a` moved them.

`robots.txt` now also disallows `/go/`, `/xmlrpc.php`, and `/wp-login.php` so Google is asked not to fetch the paths the proxy answers with 403. The proxy rule itself is not in this repo.

## Canonical alternates (the 107)

On current `main`, 23 public pages declare a canonical that is not their own URL. Every one of them is a noindex refresh stub, and none of them is in `sitemap.xml`. `go/nous/` is a separate affiliate hop, also noindex, also absent from the sitemap.

GitHub Pages also serves each directory page at `…/index.html`. That alias is the same file, so its canonical correctly points at the directory URL. There are 162 public directory indexes. Live check: `https://aitoolsessentials.com/tools/chatgpt/index.html` is HTTP 200 with canonical `https://aitoolsessentials.com/tools/chatgpt/`. Search Console's 107 is in the range of "23 stubs plus the index.html aliases Google happened to crawl." It is not a bug that points real pages at the homepage or at another host.

A public canonical that pointed off-site would be a bug. There are none. On 2026-09-15 the only non-self canonicals were six intentional redirects (the consulting page, the teacher duplicates, checkout complete, and one reports alias that has since been made self-canonical).

The sitemap writer now skips a page whose canonical is a different URL, and it skips refresh stubs even if the noindex tag is missing. After that filter the sitemap still has one URL per indexable page, and all 747 current locs return HTTP 200.
