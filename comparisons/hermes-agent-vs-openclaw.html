Hermes Agent

Open-source Hermes Agent software is available under the MIT license. Model access, Nous Portal or third-party provider usage, hosting, and infrastructure are separate cost considerations; no single universal subscription price was treated as the software price.

OpenClaw

Official OpenClaw materials describe the project as open-source and MIT-licensed. Self-hosted software cost is distinct from model API usage, hosting, maintenance, and any optional managed service.
