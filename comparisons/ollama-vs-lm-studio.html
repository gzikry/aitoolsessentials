    Evidence status

    Ollama

    Ollama supports running models on your own hardware and also offers cloud plans. Official pricing (checked 2026-10-01): Free $0 with pay-as-you-go usage credits; Pro $20/month or $200/year billed annually ($16.67/month equivalent) including $60 of usage credits per month and access to larger models; Max $100/month including $300 of usage credits per month and up to 10 concurrent requests; Team $500/month with unlimited users and $1,000 of usage credits per month shared across the team. Per-model token rates are published on the same page. Local runtime cost is separate from hardware, electricity, model licenses, and any cloud usage.

    Official docs state the local API is served at localhost:11434 by default and provide official Python and JavaScript libraries. Ollama's FAQ distinguishes local runs from cloud-hosted models and explains model storage locations. Official docs still serve the local API at localhost:11434 by default.

    LM Studio

    Official pricing (checked 2026-10-01): Free at $0 for running local LLMs on your own machine, including the Bionic Agent, llama.cpp and MLX execution, offline voice transcription, LM Link for up to 5 devices, and limited web search. Bionic+ at $20 USD/month for private, US-hosted open-source models, discounted bulk tokens, and web search with page extraction. Pro at $100 USD/month with 5x usage limits, discounted bulk tokens, and early access. Cloud inference is US-hosted with zero data retention. Centralized billing for teams is available via organizations; team subscription plans are listed as coming soon. Local hardware and model-license costs remain separate.
