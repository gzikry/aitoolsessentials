    Evidence status

    Grok

    Grok Free is $0. SuperGrok is $30/month and SuperGrok Plus is $100/month, with higher tiers above. API (docs.x.ai, checked 2026-10-01): grok-4.7 is the current flagship model at $2.00 input and $6.00 output per 1M tokens with a 500k-token context. Voice API: Agent $0.08/min, TTS $15.00 per 1M characters, batch STT $0.10/hour and streaming STT $0.20/hour. Imagine API image generation starts at $0.02/image and video at $0.05/second.

    ChatGPT

    OpenAI officially lists ChatGPT Free, Go, Plus, Pro, Business, and Enterprise. The official pricing page rendered US-dollar amounts on 2026-10-01: Free $0, Go $8/month, Plus $20/month, and Pro $100/month, billed per user per month; Business and Enterprise pricing is sales-assisted. Pro includes Pro reasoning powered by GPT-6 Astra.
