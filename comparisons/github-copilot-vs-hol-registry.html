GitHub Copilot

Copilot Free is free and limited to 2,000 completions per month, auto model selection, and an unspecified allowance of GitHub AI Credits. Copilot Student is free for verified students. Paid individual plans: Pro $10/month with 1,500 total monthly AI credits; Pro+ $39/month with 7,000; Max $100/month with 20,000. Organization plans: Business $19/user/month with 1,900 AI credits per user; Enterprise $39/user/month with 3,900. Additional usage is $0.01 per AI credit; code completions and next-edit suggestions remain unlimited on paid plans.

Open verification questions
  • GitHub does not publish a numeric AI-credit allowance for Copilot Free or Student on the plans page.
  • The public Terms do not give a blanket commercial-use warranty, non-infringement guarantee, or ownership assignment for generated Output; they only state that GitHub does not claim ownership.
  • Starting April 22, 2026, new self-serve Copilot Business sign-ups for organizations on GitHub Free and GitHub Team were temporarily paused; the official page did not publish an end date.

GitHub's Terms effective April 27, 2026 state that GitHub does not claim ownership of Copilot Input or Output. For individual licenses, GitHub and its affiliates may use Inputs and Outputs to develop, train, and improve AI/ML models unless the user opts out in account settings. The individual-license training provision does not apply when use is governed by a GitHub Customer Agreement or volume licensing agreement; those agreements control data use. GitHub says Inputs and Outputs are not shared with third-party AI model providers for those providers' independent model training. GitHub warns that Output can resemble training data or third-party/open-source code. Users must determine whether a license is required and review, test, and validate Output. GitHub's broader Terms grant GitHub and its affiliates rights to use hosted user content to develop and train AI technologies; the Copilot opt-out does not apply to public-repository content or the broader repository-content license. Re-verified 2026-10-01: The official Copilot plans documentation still matches the recorded Free/Pro/Pro+/Max and Business/Enterprise prices and AI-credit allocations; no drift detected.

HOL Registry

Free. Browsing the plugin catalogue and submitting a public plugin repository cost nothing - stated in the catalogue's own FAQ ("list your public repository for free") and in the live https://hol.org/plugins/llms.txt, which sells nothing. No paid tier exists for the catalogue itself; paid credits apply to other HOL registry operations, and HOL Guard is a separately priced product with its own plans. Verified 2026-10-14 from the live /plugins/llms.txt plus the archived catalogue page, because live catalogue HTML is served behind a Cloudflare challenge and returned 403 to every scripted client.
