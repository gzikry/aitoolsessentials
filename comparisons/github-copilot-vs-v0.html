GitHub Copilot

Copilot Free is free and limited to 2,000 completions per month, auto model selection, and an unspecified allowance of GitHub AI Credits. Copilot Student is free for verified students. Paid individual plans: Pro $10/month with 1,500 total monthly AI credits; Pro+ $39/month with 7,000; Max $100/month with 20,000. Organization plans: Business $19/user/month with 1,900 AI credits per user; Enterprise $39/user/month with 3,900. Additional usage is $0.01 per AI credit; code completions and next-edit suggestions remain unlimited on paid plans.

Official sources checked 2026-08-25

Open verification questions
  • GitHub does not publish a numeric AI-credit allowance for Copilot Free or Student on the plans page.
  • The public Terms do not give a blanket commercial-use warranty, non-infringement guarantee, or ownership assignment for generated Output; they only state that GitHub does not claim ownership.
  • Starting April 22, 2026, new self-serve Copilot Business sign-ups for organizations on GitHub Free and GitHub Team were temporarily paused; the official page did not publish an end date.

GitHub's Terms effective April 27, 2026 state that GitHub does not claim ownership of Copilot Input or Output. For individual licenses, GitHub and its affiliates may use Inputs and Outputs to develop, train, and improve AI/ML models unless the user opts out in account settings. The individual-license training provision does not apply when use is governed by a GitHub Customer Agreement or volume licensing agreement; those agreements control data use. GitHub says Inputs and Outputs are not shared with third-party AI model providers for those providers' independent model training. GitHub warns that Output can resemble training data or third-party/open-source code. Users must determine whether a license is required and review, test, and validate Output. GitHub's broader Terms grant GitHub and its affiliates rights to use hosted user content to develop and train AI technologies; the Copilot opt-out does not apply to public-repository content or the broader repository-content license.

v0

Free: $0/month, $5 monthly credits, 7-message daily limit. Premium: $20/month with $20 monthly credits, but is being sunset and is unavailable to new users. Plus: $30/user/month with $30 monthly credits per user. Business: $100/user/month with $30 monthly credits per user and model-training data opt-out. Enterprise: custom pricing and credits. Unused monthly credits roll over but expire after 65 days; purchased credits expire after one year and require an active paid plan.

Official sources checked 2026-08-25

Open verification questions
  • The official page says model token rates can be viewed in the model selector or pricing page, but the extracted live documentation did not consistently expose a complete current rate table.
  • The FAQ does not promise copyrightability, uniqueness, non-infringement, or an IP indemnity for generated code.
  • The effect of deleting content already incorporated into a trained model is limited: the FAQ says existing models will not be updated after such a deletion request.

Official documentation describes v0 as an AI agent for producing full-stack apps and agents, with Git integration, a full editor, previews, backend connections, and Vercel deployment. v0 may use user prompts or generated content with third-party models and learning systems to improve products. Enterprise content and content from customers who opt out in Vercel settings are not used for training. Vercel platform-service customer data or code is not used to train, improve, or fine-tune v0 models. The FAQ says Vercel does not own code generated from user prompts, while warning that output may resemble other output or third-party IP and must be evaluated by the user. Pricing terminology on the retrieved current documentation uses 'Plus'; some indexed official snippets still use the former name 'Team'.
