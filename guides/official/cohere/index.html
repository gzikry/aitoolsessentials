Cohere Official Guides

Curated summary of official Cohere guides covering Command family models, enterprise RAG, and automation.

Key Takeaways

  1. Command A+ is Cohere’s open-source flagship: 218B total / 25B active parameters with multimodal agentic task support.
  2. Official docs prioritize enterprise retrieval, embeddings, and reranking with explicit migration paths for deprecated models.
  3. North Automations docs describe workflow orchestration, governance, and model selection per task step.
  4. Guides include multilingual deployment notes, safety benchmarks, and multilingual model families like Tiny Aya.
