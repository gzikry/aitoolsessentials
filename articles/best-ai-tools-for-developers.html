    How this stack is chosen

    Developer tooling decisions hinge on two things beyond raw quality: whether your code trains vendor models (Cursor: no unless opted in; check each vendor's current policy) and where suggestions run (local context vs cloud). Prototype builders like v0 and Bolt are for scaffolding, not production paths.
