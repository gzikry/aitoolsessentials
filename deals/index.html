    Free-plan tools to test first

    AI Agents · Free (97 templates; no paid tier, sponsorship-funded)

    BotLoadout

    A free library of 97 AI agent templates, each published in separate Claude, ChatGPT and Grok versions with the system prompt, the connectors to switch on, a short setup sequence, an example input and output, and stated limits. The full prompt text is public and there is no hosted runtime: the templates are copied into your own account, and the site is funded by newsletter sponsorship rather than subscriptions.

    Best for: Starting a first Claude, ChatGPT or Grok agent from a worked template instead of writing the system prompt, connectors and setup from scratch
