# Hands-On Review Template

When you test a tool, fill this in and give it to Hermes — it slots into the review page automatically.

## Per tool, capture:
1. **Test scope** — what task(s) you ran, on which plan (free/paid), over how long
2. **What worked** — 2-3 specifics ("transcribed a 40-min call with 2 speakers, ~98% accurate")
3. **What broke / annoyed** — 2-3 specifics with context
4. **Surprise** — one thing marketing doesn't mention
5. **Verdict vs editorial score** — does real use confirm or adjust the score?
6. **Screenshots** — 2-3 (results, pricing page as-rendered, any error states)
7. **Cost actually incurred** — what the test cost you (credits burned etc.)

## Rules
- Same evidence bar as pricing: no invented numbers, dates on everything
- Update review page: hands_on_status → tested, swap "not yet published" label for "Hands-on tested YYYY-MM-DD"
- Add a "## Hands-on results" section after Overview with your specifics
- If the score changes, note why in the score card evidence line

## Priority order (from tools.json hands_on_priority)
Test tools that are (a) affiliate-earning first — ElevenLabs, Make — then (b) highest-traffic reviews — ChatGPT, Claude, Perplexity.
