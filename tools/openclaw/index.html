Frequently asked questions

Is OpenClaw free?

The official project is open source and MIT-licensed; model API usage, hosting, and optional managed services can still cost money.

What should I secure first?

Protect the gateway, restrict network exposure, use least-privilege credentials, review extensions, and separate personal data from experiments.

Who should avoid it?

Teams that need a managed, compliance-ready service without owning deployment, updates, monitoring, and incident response should evaluate hosted alternatives first.
