Frequently asked questions

What is the current Grok model?

The flagship is Grok 4.6 (August 2026), focused on long-running agents and visual work, at $2 input / $6 output per million tokens. Prior flagships Grok 4.5 (July 2026) and Grok 4.3 remain available, with Grok 4.3 cheaper at $1.25 / $2.50.

What is Grok Build?

Grok Build is xAI's coding agent: a terminal harness (now open source) with Workflows that fan tasks out across parallel agents, /goal for long-running autonomous execution, an Agent Dashboard for many simultaneous sessions, and a plugin marketplace. Build Mode extends it to creating and sharing full websites, apps, games, and interactive dashboards.

What are Grok Bots?

Grok Bot, introduced August 2026, is a team of always-on agents with their own computer that work inside your tools and apps around the clock — you assign jobs and they keep executing.

How much does Grok cost?

There's a free tier. SuperGrok is $30/month, SuperGrok Plus $100/month, with higher tiers for heavy use. API access starts around $1–$2 per million input tokens depending on model.

Can I use Grok inside other coding tools?

Yes. Grok 4.5/4.6 are available in GitHub Copilot, and SuperGrok/X Premium subscriptions work inside Warp, Kilo Code, OpenCode, Kilo Code, and Hermes Agent.
