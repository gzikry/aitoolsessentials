Frequently asked questions

Is Hermes Agent free?

The software is open source under the MIT license; model access, hosting, and optional provider services can create separate costs.

What makes Hermes different from a coding copilot?

It combines tools, memory, skills, messaging, scheduling, and multi-agent delegation rather than living only inside an editor.

Is Hermes safe by default?

Treat tool access as powerful automation. Start with least privilege, review command approvals, isolate risky workloads, and never store secrets in project files.
