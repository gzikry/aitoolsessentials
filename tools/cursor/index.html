Overview

Developer-focused AI editor with its own frontier models (Grok 4.6 jointly trained with xAI, Composer 2.5), agent requests, cloud agents, and Bugbot code review.

Key features

  • Cursor Grok 4.6 — jointly trained by Cursor and xAI; flagship coding model in-editor

Pricing

Official sources checked 2026-08-25

Current official summary: Cursor Free includes limited agent requests and Composer access. Pro $20/mo, Pro Plus $60/mo, Ultra $200/mo, Teams $40/user/mo, Enterprise custom (cursor.com/pricing, checked 2026-08-25). Cursor Models pool: Grok 4.6 $2/$6, Composer 2.5 $0.50/$2.50 per 1M tokens.

Open verification questions
  • The pricing UI exposes a Teams Premium option with 5x Standard Agent limits, but its price was not reliably exposed in the official page's static content, so no price is reported.
  • The public Terms assign Anysphere's rights in Suggestions but do not provide a blanket warranty that generated code is non-infringing or expressly guarantee commercial suitability.

The official Terms state that Anysphere will not use Content to train, or allow a third party to train, AI models unless the user explicitly agrees. The Privacy Policy identifies limited exceptions for security review, explicitly submitted feedback, or explicit training consent. Privacy Mode is available on free and paid individual plans; Cursor says that when enabled it will not train on the user's data and applies contractual and technical controls to model providers. Users retain their rights in Inputs, and Anysphere assigns to users any right, title, and interest it has in Suggestions. Official documentation describes Cursor as a coding agent for understanding codebases, planning and building features, fixing bugs, reviewing changes, and using integrations, MCP, rules, skills, hooks, cloud agents, and CLI workflows.

Frequently asked questions

What models does Cursor offer?

Cursor's own pool includes Grok 4.6 and Grok 4.5 (jointly trained with xAI) plus Composer 2.5, its price-efficient agentic model. Frontier models from OpenAI, Anthropic, Google, and xAI are available in a separate pool billed near API rates.

How much is Cursor?

Free tier with limited agent requests and Composer access; Pro $20/mo, Pro Plus $60/mo, Ultra $200/mo, Teams $40/user/mo, Enterprise custom.

What is Composer 2.5?

Cursor's own agentic coding model, tuned for long-horizon tasks via reinforcement learning. Standard pricing is $0.50 input / $2.50 output per million tokens; Fast mode is $3 / $15.
