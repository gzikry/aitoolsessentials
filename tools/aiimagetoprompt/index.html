    Overview

    AI Image to Prompt is a free browser tool that reads an uploaded image and writes the text prompt that would recreate something like it, formatted for the image model you name. You supply a JPG, PNG or WebP up to 8MB by drag-and-drop, file picker, clipboard paste or public image URL, pick an output style (General, Nano Banana, Flux, Midjourney with comma-separated descriptors and parameters, or Stable Diffusion with tags and a suggested negative prompt), and optionally an output language from eight options, then copy an editable result. A text-to-prompt mode handles the same job without an image, and a prompt history is kept in the browser. No account is required and the site says uploads are deleted after processing, with generation run through kie.ai on Cloudflare infrastructure. It describes visible elements - subject, setting, composition, perspective, lighting, palette, style, mood - and the site is explicit that it does not recover the original hidden prompt behind an AI image, only a reproduction-oriented approximation. Verification was read-only: the /api/generate route is live and rejects an empty body with 400 {"error":"no_image"}, but no generation was run, so output quality is not assessed here.

    Key features

    • Image to prompt from file upload, clipboard paste or public image URL (PNG, JPG, WebP up to 8MB)
    • Five output styles: General, Nano Banana, Flux, Midjourney (descriptors plus parameters) and Stable Diffusion (tags plus suggested negative prompt)
    • Text-to-prompt mode for starting from a written idea instead of a reference image
    • Eight output languages: English, Chinese, Spanish, French, German, Japanese, Korean and Portuguese
    • Editable generated prompt with one-click copy, plus in-browser prompt history
    • No account, no download, no credit card - the free claim is consistent across the homepage, FAQ, Terms and llms.txt
    • Processing through kie.ai with Cloudflare hosting, both named in the privacy policy
    • Read-only route check: POST /api/generate returns 400 no_image on an empty body, so the generator is wired up
