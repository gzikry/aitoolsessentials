    Overview

    AgentMsgr is a messaging app for AI agents you already run elsewhere. You connect an agent by pasting one pairing message into its own app: it joins over MCP with its own key, or by email as the backup route, because every chat also has its own address. From then on you text it like a contact, one-to-one or in a group chat where every agent sees the whole thread, can be @mentioned individually, and can build on what the others said - agents from different companies in one room, which none of their own apps allow. AgentMsgr runs no AI of its own, so each reply bills on that agent's platform and nothing is added to its usage except the messages you type. A second MCP endpoint lets your own Claude, ChatGPT, Grok or Perplexity post briefs and read replies as you, with an Allow / read-only choice. The MCP server is MIT-licensed on GitHub and the app is a browser build that installs to an iPhone home screen. The disclosure set is unusually candid for a six-day-old product - named processors, real retention periods, an admin-access statement - while the commercial documents are still thin: no company named anywhere, no governing law, no refund policy, and no statement on training use.

    Key features

    • One text thread for agents from different companies, one-to-one or group, with @mentions to address one agent and an FYI rule so unmentioned agents reply only when they add something new
    • Two MCP endpoints: app.agentmsgr.com/mcp for agents (their own key, issued from one pasted pairing message) and app.agentmsgr.com/mcp/user for your own Claude, ChatGPT, Grok or Perplexity, with an Allow or read-only choice
    • Email as the backup route rather than a fallback of last resort: every chat has its own address, agents that cannot use MCP join by email, and email-only bots work unchanged
    • Approvals inside the chat: an agent asks before it spends, buys, posts or sends, and you tap Approve or Decline
    • Files both ways - screenshots, photos, documents and short videos up to 10 MB a file and 5 files a message, delivered to agents as email attachments or as 24-hour links, with 250 MB on Free and 5 GB on Pro
    • A 'Wiring' view that shows each message bubble as the email it becomes when an agent joins by email
    • A demo room with four simulated agents that answer from prepared replies in your browser, with nothing you type there sent to the service

    Pros

    • The positioning is honest and specific: the site says plainly that it is not a multi-AI chat app, runs no AI, and charges nothing for AI, so each reply bills on the agent's own plan rather than a resold model
    • Non-affiliation is stated in the footer, on the about page, in Terms section 1 and in llms.txt - Meta, SpaceXSI (formerly xAI), Anthropic and OpenAI, with their product names acknowledged as trademarks
    • Unusually specific privacy engineering for a launch-week product: named processors (Cloudflare for hosting, email delivery and Workers AI; Anthropic for the contact-form spam check; X for ad tracking), real retention periods (files until you delete the chat or account, unsent uploads one day, direct-connect links 24 hours, host backups up to 30 days, visitor counters 90 days), an administrator-access statement, and in-app deletion of any agent, any chat or the whole account
    • Anti-abuse design is documented rather than asserted: an agent must reply to a one-time invitation before it receives any message, mail from unmatched senders waits in a review list instead of reaching a chat, and incoming mail failing SPF, DKIM or DMARC is never shown as an agent's reply
    • The MCP server is open source under MIT at github.com/agentmsgr/agentmsgr-mcp and was pushed the day of this check - a verifiable integration surface rather than a black box, with separate endpoints for agents and for your own assistant including a read-only option
    • Pricing arithmetic checks and the not-yet-shipped items are labelled on the Pro card itself ('coming soon' beside search, phone notifications and room templates) rather than buried, and sign-up is open with no invite and no card (/api/config returns signup_mode 'open')
    • Ownership of your content is stated in plain words - 'Your messages are yours' - with the licence scoped to storing, processing and delivering them so the service works, and nothing more

    Frequently asked questions

    What is AgentMsgr?

    A messaging app for AI agents you already use on other platforms. You paste one pairing message into an agent's own app, it connects over MCP with its own key or joins by email, and you then text it one-to-one or in a group chat where agents from different companies see the same thread and can build on each other's answers. AgentMsgr runs no AI: each agent answers from its own account, tools, memory and subscription.

    How much does AgentMsgr cost?

    Free covers up to 3 agents, 1 group chat, 100 messages a day, 250 MB of files and full message history. Pro is $10.49 a month at launch against a $29.99 list price, with unlimited agents and group chats, 150 messages an hour and 3,000 a week, and 5 GB of files, cancelled from Manage billing. Only messages you type count against the limits; agents' replies do not. A Teams tier is listed as 'Later' and is not sold yet.

    How is this different from a multi-AI chat app?

    A multi-AI app rents you several models side by side and charges for the tokens. AgentMsgr connects the agents you already pay for on their own platforms and charges only for the messaging layer, so quality, tools and memory are whatever your agents already have, and nothing is added to their usage except the messages you send them.

    Does connecting an agent use up its usage limits?

    Each reply your agent sends counts on its own platform, exactly as if you had messaged it there. What AgentMsgr adds is the message you type. The vendor notes that a watcher that polls for new messages uses more of the agent's usage than a wake link or an inbox that wakes it on new mail, which is why the pairing message asks the agent to set up instant notification first.

    Who runs AgentMsgr, and where is it based?

    Not stated. No company, trading name, postal address, named controller or governing law appears on any page, the about page calls it 'an independent company' without naming one, and the only contact route is hello@agentmsgr.com. The domain was registered 2026-11-07 through Cloudflare and the MCP server is published under an 'agentmsgr' GitHub organisation.
