Overview

A flexible automation platform for technical teams that want deeper workflow control and self-hosting options.

Key features

  • Open source — self-host for unlimited runs at zero cost
  • Code steps in JavaScript/Python when nodes aren't enough
  • Advanced logic: loops, error branches, sub-workflows
  • 400+ integrations plus generic HTTP node
  • AI agent nodes with LangChain support

Trial checklist

Who n8n is for

n8n fits teams and individuals who need technical workflow automation with self-hosting and ai agent options. It is strongest in automation work where output quality and speed matter more than deep customization. Skip it if you need a self-hosted option or heavy API control on a budget plan.
