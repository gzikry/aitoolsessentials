    Overview

    A free, vendor-scored catalogue of installable coding-agent plugins across Claude Code, Codex, Cursor, MCP, Grok, Kimi Code, DeepSeek Harness, Antigravity CLI, and OpenCode. Genuinely useful for discovery; its security signals are static catalogue scans, not install guarantees.

    Key features

    • One catalogue spanning Claude Code, Codex, Cursor, Grok, Kimi Code, DeepSeek Harness, Antigravity CLI, OpenCode, and MCP
    • Trust score blending identity, activity, and verification signals, sortable by newest or featured
    • Scanner-backed signals documented publicly, including secret scanning and provenance checks where available
    • Per-plugin pages with runtime-specific install commands and named publishers
    • Free GitHub-connected submission that opens a pull request on the list the catalogue ingests
    • Daily plugin launch feed
    • Published plugin-security dataset on Hugging Face stating its own scope and row counts

    Trial checklist

    Use a real task, not a browse: search for one plugin you already run and one gap in your agent setup. Note whether the install command, publisher identity, and trust signals tell you anything you did not already know from the plugin's own repository. Then submit one of your own public repos through the free flow and see what it actually requires. Pay particular attention to the fallback static scan caveat. Compare the result against simply searching GitHub before deciding.

    Pros

    • Free to browse and free to submit a listing — stated on its own catalogue FAQ, not just marketing copy
    • Operator is named on the site (Hashgraph Online DAO LLC) with a published business address and telephone
    • Nine ecosystems in one catalogue, including skills, MCP servers, and apps

    Cons

    • Trust and security scores come from a fallback static catalogue scan, not live exploit testing, so a high score is a weak signal
    • Catalogue size disagrees between its own surfaces (243 plugins on the 2026-08-31 catalogue page vs 205 in the current llms.txt)
    • No general site-wide Terms of Service page was found — the footer's "Terms of Service" opens the HOL Points legal page
    • Operator is a Marshall Islands DAO LLC, an offshore jurisdiction, and the domain registrant is privacy-shielded in WHOIS
    • Live catalogue HTML sits behind a Cloudflare challenge, which blocks scripted readers and some agent clients
    • Community upvotes and GitHub activity are surfaced as proof signals but measure popularity, not quality
    • The wider HOL platform is Hedera-backed and some records are written to public chains — permanent and visible by design

    Frequently asked questions

    Is HOL Registry free?

    Yes — browsing is free and submitting a public plugin repository is free. Paid credits apply to other HOL registry operations, and HOL Guard is a separate paid product.

    Do the trust scores mean a plugin is safe?

    No, and the site says so itself. Scores come from a fallback static catalogue scan, not a live exploit test, so treat them as one weak signal among several.

    How is this different from a plain MCP server list?

    It indexes plugins, skills, MCP servers, and apps per ecosystem, and keeps catalogue plugin counts separate from its Registry Broker agent counts.

    Who runs it?

    Hashgraph Online DAO LLC (HOL), a Hedera-ecosystem organisation. It publishes a Marshall Islands business address, a phone number, and support@hol.org.
