Pricing

Official sources checked 2026-09-01

Current official summary: TypingMind offers one-time lifetime licenses: Standard at $39 (basic chat, AI agents, voice input, chat sharing), Extended at $79 (adds image generation, web search, text-to-speech, vision/images, document upload), and Premium at $99 (discounted from $198, adds multi-model chats, unlimited plugins, projects and folders, artifacts, free updates). A Bulk License for up to 10 users on 50 devices is $395 (discounted from $790). TypingMind for Teams is available as a separate custom portal. All plans are one-time payments; price does not include API costs (users supply their own API keys) or additional cloud storage. A 14-day money-back guarantee is offered.

Open verification questions
  • The $99 Premium price is a limited-time 50% off discount; the regular price is $198 and may revert.
  • API costs are separate and depend on the user's chosen model provider and usage; TypingMind does not publish or control those rates.
  • The self-hosted version provides compiled code only, not source code; modification rights are not granted.

Official pricing page (typingmind.com/buy) checked 2026-09-01. TypingMind is a BYOK (bring-your-own-key) LLM frontend; users connect their own OpenAI, Anthropic, Google, or local Ollama API keys and pay providers directly for usage. The app is not open-source; self-hosting is available with a license key but only the compiled code is provided. The homepage states data is stored locally by default and conversations are not used for AI training. The Premium tier was advertised at 50% off ($99 from $198) as a limited-time offer.

Pricing changes often — verify current plans on the official site before buying. Dated snapshots: Pricing Watch.
