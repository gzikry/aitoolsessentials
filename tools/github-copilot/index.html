    Trial checklist

    Pricing

    Last checked 2026-11-14

    Current official summary: Copilot Free is free and limited to 2,000 completions per month, auto model selection, and an unspecified allowance of GitHub AI Credits. Copilot Student is free for verified students. Paid individual plans: Pro $10/month with 1,500 total monthly AI credits; Pro+ $39/month with 7,000; Max $100/month with 20,000. Organization plans: Business $19/user/month with 1,900 AI credits per user; Enterprise $39/user/month with 3,900. Additional usage is $0.01 per AI credit; code completions and next-edit suggestions remain unlimited on paid plans.

    Open verification questions
    • GitHub does not publish a numeric AI-credit allowance for Copilot Free or Student on the plans page.
    • The public Terms do not give a blanket commercial-use warranty, non-infringement guarantee, or ownership assignment for generated Output; they only state that GitHub does not claim ownership.
    • Starting April 22, 2026, new self-serve Copilot Business sign-ups for organizations on GitHub Free and GitHub Team were temporarily paused; the official page did not publish an end date.

    GitHub's Terms effective April 27, 2026 state that GitHub does not claim ownership of Copilot Input or Output. For individual licenses, GitHub and its affiliates may use Inputs and Outputs to develop, train, and improve AI/ML models unless the user opts out in account settings. The individual-license training provision does not apply when use is governed by a GitHub Customer Agreement or volume licensing agreement; those agreements control data use. GitHub says Inputs and Outputs are not shared with third-party AI model providers for those providers' independent model training. GitHub warns that Output can resemble training data or third-party/open-source code. Users must determine whether a license is required and review, test, and validate Output. GitHub's broader Terms grant GitHub and its affiliates rights to use hosted user content to develop and train AI technologies; the Copilot opt-out does not apply to public-repository content or the broader repository-content license.     Who GitHub Copilot is for

    GitHub Copilot is aimed at teams and individuals who need autocomplete, code chat, and developer productivity in popular ides. It is designed for development workflows where output quality, adoption effort, and operating cost all matter. Compare alternatives first if you require self-hosting, unusually deep customization, or tighter policy controls than the official plan provides.

    How GitHub Copilot compares

    In development, GitHub Copilot sits next to Bolt.new, CCC (Claude Command Center), Cursor and 5 others. The useful part is broad ide support. The part to price first is quality varies by task. Read the side-by-side before you pay for a second seat.

    How we evaluated

    Job fit 5 - inline completion and chat inside the IDE plus GitHub-native review covers the recurring parts of professional development. Output quality 4 - dependable on routine work, variable on harder tasks, and it can echo problems already present in the codebase. Adoption 5 - the lowest-friction adoption of any coding assistant because it meets teams wherever they already work. Cost 4 - paid-only and enterprise licensing is per-seat, which is where the discount comes from. 4.5 for breadth rather than peak capability.
