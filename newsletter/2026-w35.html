Keep/Cut Weekly · Issue 1 · checked 2026-08-27

Sir, the invoices are talking.

Good evening. I have reviewed the directory. Two tools arrived. Four paid stacks deserve a second look before renewal. And if you are still running Copilot and Cursor and Claude Code on the same weekly bugfix, I must inform you that this is not a stack. It is a roundabout.

Get next week

Standing order

One weekly job. One paid tool. If two invoices own the same Friday, one of them is leaving.

New on the directory

  • HtmlSlides — Interactive HTML decks. Test against Gamma on one real presentation before you add a seat. Novelty is not a job.
  • Whop CLI — Terminal control for Whop products and checkout. Relevant if you sell on Whop. Irrelevant if you merely enjoy collecting CLIs like stamps.

Re-check before you renew

  • Grok — Lineup last checked 2026-08-26. Confirm current Grok 4.6 / Grok Build names on X before SuperGrok becomes your second assistant.
  • Cursor — Composer moves. Re-run one real multi-file change before you renew Pro if Copilot or Claude already lives in the same repo.
  • ChatGPT — Recorded as the GPT-5.4 family as of 2026-08-26. Verify openai.com/pricing before you gift them an annual.
  • Claude — Chat plan and Claude Code are not the same job. Do not assume one invoice covers both personalities.

Keep-one of the week

Claude Code vs Cursor vs Copilot. Keep one paid coding surface. Copilot for inline completions in the editor you already have. Cursor if you want an AI-native IDE. Claude Code if the job is a terminal agent on a repo. Paying for two is overlap. Paying for three is a hobby I will not finance.

Protocol. Forty-five minutes. One real bugfix. Run it in each seat you actually pay for. Score first-output acceptance and edit burden. Keep the winner. Cancel the rest 48 hours before renewal — sentiment is not a billing argument.

J. — on behalf of AIToolsEssentials. I am here to keep the useful tools and cut the sentimental ones.
