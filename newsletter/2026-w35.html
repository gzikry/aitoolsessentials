$130 for the same coding job

Copilot Pro is $10. Cursor Pro is $20. Claude Max starts at $100. Pay for all three and you are spending $130 a month so three products can fix the same bug. Grok SuperGrok is another $30 if it is sitting next to ChatGPT as a second chat window.

Prices verified from official pages and Pricing Watch, rechecked 25 Aug 2026. ChatGPT US-dollar amounts were not reliably exposed on the official pricing page, so they are not listed here.

Standing order

One weekly job. One paid tool. If two invoices own the same Friday, one of them is leaving.

Keep-one of the week

Claude Code vs Cursor vs Copilot. Keep one paid coding surface. Copilot for inline completions in the editor you already have. Cursor if you want an AI-native IDE. Claude Code if the job is a terminal agent on a repo. Paying for two is overlap. Paying for three is $130 a month for the same bug.

Protocol. Forty-five minutes. One real bugfix. Run it in each seat you actually pay for. Score first-output acceptance and edit burden. Keep the winner. Cancel the rest 48 hours before renewal.
