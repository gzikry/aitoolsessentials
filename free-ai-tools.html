    Free AI tools

    Start free. Upgrade only when limits hurt.

    We found 75 tools in the directory with a free tier or free self-hosted option. This hub groups them by job so you can test before paying.

    Quick answer

    The best free AI tool depends on the constraint.

    For general work, start with ChatGPT, Claude, Gemini, or Perplexity. For visuals, compare Canva AI, Adobe Firefly, Leonardo AI, and Midjourney's trial availability. For automation, Make and Zapier are easiest; n8n is the free self-hosted option if you can run it yourself.

    Free tiers change quickly. Every linked review includes an official-pricing block and verification date.

    TheFaceRating

    TheFaceRating turns one selfie into a face rating. Google's MediaPipe face mesh places 478 landmarks in the browser, the site levels the head on the iris line and scores 11 proportions into a single 0-100 harmony number, then names the face shape across six prototypes and shows symmetry, canthal tilt, facial thirds and width-to-height ratio against a reference band. It also returns a celebrity bone-structure 'twin' as a percentage. The free scan needs no account, and we confirmed by running it that the measuring step sends nothing: landmarks, ratios and the result page are produced with no outbound request. The paid report adds 14 try-on renders on the buyer's own photo - six hairstyles, four necklines, four eyewear frames - plus a 12-season colour palette, a styling guide and, on Pro and VIP, a 30-day plan, a PDF and Studio credits for rating any look you find. Colour analysis is the one step that needs the photo, and the site asks for it with an unticked consent choice that can be declined while still returning full geometry results. Reports are sold by Vban LLC, a Wyoming company, under Wyoming law.

    Best for: Anyone who wants a fast, private read on facial proportions before spending money on a haircut, a pair of glasses or a colour palette, and who reads the score as a styling starting point rather than a verdict on attractiveness. Also a useful sandbox: the Studio scores any reference photo against your own face. Not a fit for readers who want the rating to mean something objective, who need a working support mailbox before they pay, or who would rather not involve a face at all - the free scan keeps the photo on the device, but the colour analysis and every try-on require sending a compressed copy to the vendor and its model providers.

    CCC (Claude Command Center)

    CCC (Claude Command Center) is a local dashboard for people running several coding agents at once. Instead of owning execution, it reads each engine's on-disk state as the source of truth, so a session you started in a terminal, resumed by hand or launched headless outside the dashboard still shows up on the board - that is the difference between a dashboard and a second place you have to remember to work from. On top of the board it adds a needs-attention lane that flags sessions ending on a real question, a per-session context meter, plan-usage and rate-limit projections, a Kanban with a project tree and an infinite Flow canvas, group chats between agents, a work queue with verify-to-close receipts, git worktrees per task, and an optional fallback that keeps a limit-hit session running on a $0 model. The stack is deliberately plain: a stdlib-only Python server bound to 127.0.0.1 and a no-build vanilla-JS UI, with readable JSON state under ~/.claude/command-center/. Claude Code is first-class; Codex, Cursor, Antigravity, Kilo Code, Kimi Code, OpenCode and Devin spawn and ingest with documented gaps. Version 5.39.0 shipped 2026-10-18 and the repository was pushed the same day this review was written.

    Best for: Developers who already run several coding agents and keep losing track of them in terminal tabs. CCC is worth a look if you launch Claude Code, Codex, Cursor and friends from a terminal and want one local board that shows every session, which one is waiting on you, and which has quietly run out of context - without routing your work through someone else's cloud. It is not a fit for a single-session user (a terminal is enough), for anyone who wants a hosted team product with accounts and permissions, for a Windows or Linux shop expecting parity with the macOS app, or for a buyer who needs a company entity and a governing-law clause before installing software.
