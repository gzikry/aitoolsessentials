    Raspberry Pi 5 (8GB or 16GB) gateway

    Buy for an inexpensive always-on gateway, not for serious local model inference.

    Raspberry Pi · low-power ARM gateway

    Evidence boundary

    “Compatible” means the documented operating system/runtime path is plausible or official. It does not guarantee a particular model, speed, driver, thermals, or local inference quality. Always test the exact model and version before buying for a production workload.

    What the official source says

    Raspberry Pi lists a 2.4GHz quad-core Cortex-A76 CPU, 1GB/2GB/4GB/8GB/16GB RAM variants, Gigabit Ethernet, PCIe 2.0 x1, USB 3, and recommends a 5V/5A USB-C supply and active cooling for Pi 5 workloads. The official page lists the 16GB model at $305 during this check.

    Local-AI fit

    Excellent low-power always-on gateway for OpenClaw with cloud models, lightweight webhooks, messaging, and remote orchestration. Not a sensible primary host for modern local LLM inference; use it as a control plane and point models elsewhere.

    Specifications that matter

    • memory: 4GB is enough for a simple gateway; 8GB is a comfortable target; 16GB is unnecessary for most gateway-only deployments.
    • storage: Prefer USB SSD or an M.2 SSD over a heavily written microSD card for state, logs, and databases.
    • os: 64-bit Raspberry Pi OS is the documented path; OpenClaw documents ARM64 support and Raspberry Pi deployment.
    • thermal: Use active cooling and the official 27W supply for sustained operation; under-powering or passive cooling can reduce reliability.
